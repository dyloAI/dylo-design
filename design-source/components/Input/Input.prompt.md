Text field with a mono uppercase label and an oxide focus ring — the focus state is the one place a form spends the accent.

```jsx
<Input label="Work email" placeholder="you@company.com" hint="We reply within a day." />
<Input label="Project" placeholder="What are we building?" />
<Input label="Locked" disabled value="—" />
```

Label is mono/uppercase; field is Space Grotesk. Keep hints short and factual.
